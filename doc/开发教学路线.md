## 课程总原则

- 程序拥有状态、权限、预算、证据账本和终止条件。
- LLM 只草拟假设、验证判断、摘要和人工建议，不直接调用 Splunk。
- 每个 conclusive 根因必须引用真实、当前可见的查询证据。
- `INCONCLUSIVE` 表示流程正常但证据不足；`FAILED` 表示能力或策略失败。
- KnowledgeSnapshot 帮助解释系统，ScopePolicy 才能授予查询能力。
- normalized 不等于 sanitized；生产数据在 Redactor 和字段分类验收前不外发。
- 版本、哈希和结构化 decision code 用于审计；原始日志、record_ref、raw SPL 和模型私有推理不进入默认 Trace。
- 外部契约未知时明确阻塞，不用猜测出来的 API 冒充实现。
